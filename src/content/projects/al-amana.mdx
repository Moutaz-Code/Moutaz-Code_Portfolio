A 3D adventure made in three days for a heritage game jam.

I owned the visuals. The post stack is built on NullTale's [VolFx](https://x.com/NullTale) dither, colour-map and
screen-outline effects. My job was getting them to read well together, including tinting the scene so the palette
survives the dithering. I also wrote the shaders for the sand dunes, the day–night transition and a view-angle effect,
set up the lighting, and built particle systems that follow set movement paths.
