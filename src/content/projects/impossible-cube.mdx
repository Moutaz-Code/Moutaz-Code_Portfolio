A practice piece before a jam: a hollow cube where each face is a window into its own little world. The worlds live in
the same space but you can only see each one through its own face.

Each face is a quad with a tiny shader that draws nothing (`Blend Zero One`, `ZWrite Off`) and writes that face's ID
into the stencil buffer. The contents of each world sit on their own layer, which is removed from the renderer's normal
opaque pass. A URP Render Objects feature per layer draws them back in with a stencil test of *Equal* against that
face's ID. Each world only appears through its matching face, at the cost of one extra filtered draw per world.
