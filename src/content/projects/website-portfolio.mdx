The first version of this site had a CMS, a search index, smooth scrolling, a custom cursor and a few animation
libraries. It was more site than I could keep updated. This version is static: each project is one MDX file with a
schema, and adding a project means adding a file and a folder of media.

## The deck

The projects on the home page are a hand of cards in three.js. Each face is drawn with Canvas2D (frame, title, art,
type line, text) and uploaded as a texture, so a card is two textured quads and costs almost nothing to draw. Cards are
dealt from a pile, fanned in the hand, and can be clicked or dragged onto the table and flipped to show what I did.
Positions, rotation and flips are eased with frame-rate-independent exponential smoothing, and the filters send cards
back to the pile instead of rebuilding the scene.

## Shader windows

Each shader on the home page has a recorded clip from the original project and a live WebGL window running a port of
the technique: a Sobel outline on a normals buffer, stencil-buffer portals, and the cartoon sky. Every view registers
with one shared animation loop and only renders while it's on screen. With reduced motion turned on, nothing
animates by itself.
