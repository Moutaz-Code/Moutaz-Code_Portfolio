Deliver parcels across a distant kingdom and uncover its secrets along the way.

This was my first big game and my first time using Unity. We built it as a vertical slice during Endless Studios'
six-month programme. It won Best Art Direction at Endless Studios' UAE GameMakers competition. Afterwards we kept
working on it, fixing bugs and getting it ready for an itch.io release.

I built the core gameplay: player controls, the interaction system and terrain generation. I also wrote custom shaders
and set up the in-game lighting, and later debugged and optimised the gameplay systems so the build ran smoothly.
