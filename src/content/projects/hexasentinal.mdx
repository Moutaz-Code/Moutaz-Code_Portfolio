Forensic tools are good at extracting evidence. What investigators still do by hand is everything after that:
reviewing findings, reconstructing timelines, correlating artefacts and writing reports. HexaSentinal is a Windows
workstation for that second half, and it runs **entirely offline**, so evidence never leaves the machine. That makes it
usable in air-gapped labs where cloud tools are off the table.

It was our graduation capstone at Abu Dhabi University, built by a team of four. I was responsible for the system
design and architecture, made most of the technical decisions and wrote much of the implementation.

## Architecture

A .NET 8 solution split into projects with one job each: the WPF interface, core contracts, domain models,
persistence, ingestion, analysis, reporting and shared utilities, plus a test project. The interface talks to services
through interfaces and view models, so it never touches SQL, file storage rules or report generation directly. That
separation is what let four people work on it at once.

Data lives in a local SQLite database, and each case gets its own folder for evidence and reports.

## The workflow

- **Ingestion.** A pipeline validates the file, computes its SHA-256 hash, copies it into the case's evidence store
  (keyed by the hash) and writes an audit entry. If the same hash already exists in the case, it warns about a duplicate.
- **Analysis.** Readable evidence is scanned for forensic keywords, each hit is given a risk level from Low to Critical,
  and the matched context is kept next to it. The point was **explainability**: an investigator can always see why a file
  was flagged instead of getting an unexplained alert.
- **Timeline.** Timestamp patterns are pulled out of evidence with their source file and line, alongside the audit trail
  of everything done in the case.
- **Assistant.** If a local Ollama server is running, the assistant builds a case-aware prompt from the case, evidence,
  analysis results and recent audit entries. If it isn't, the rest of the app works normally and the assistant explains how
  to start it. An optional model should never be able to break an investigation.
- **Reports.** Executive, technical, legal and timeline PDFs, generated locally with QuestPDF.

## Scope

It's a capstone, not a production forensic suite, and the report says so plainly. The analysis is strongest on
text-readable evidence. OCR for images, speech-to-text for audio and full disk-image parsing were designed for but
left as future work, and the user roles are a foundation rather than enforced access control.
